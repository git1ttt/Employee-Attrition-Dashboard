# Employee Attrition Dashboard (Power BI)

This project analyzes employee attrition trends using Power BI.

## Features
- Department-wise attrition analysis
- Job role comparison
- Age distribution of employees
- Interactive slicers (Department & Attrition)
- KPI card showing total employees left

## Tools Used
- Power BI

## Files Included
- Employee_Attrition_Dashboard.pbix
- Dashboard Screenshot

## Insights
- Higher attrition observed in Research & Development
- Certain job roles show higher turnover
- Age distribution helps identify risk groups
